# Day 2 - Networking Basics

## Topics Learned

- IP Address
- MAC Address
- DNS (Domain Name System)
- DHCP (Dynamic Host Configuration Protocol)

## Key Concepts

- IP Address is a logical address used to identify a device on a network.
- MAC Address is a hardware address associated with a network interface.
- DNS converts domain names into IP addresses.
- DHCP automatically provides IP addresses and network configuration to devices.

## Day 2 Quiz

- IP Address → Logical address
- MAC Address → Hardware address
- DNS → Resolves domain names to IP addresses
- DHCP → Automatically assigns IP addresses
